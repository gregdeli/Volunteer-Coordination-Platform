# Disaster Management System

## Project Overview

This project involves the development of a comprehensive **Disaster Management System** designed to facilitate effective response and coordination during emergency situations. The system caters to different user roles, including **Administrators**, **Rescuers**, and **Citizens**, providing tailored functionalities for each group to ensure efficient disaster management.

## Key Features

### For Administrators
- User management (add, edit, delete users)
- Resource allocation and tracking
- Emergency event creation and management
- Data analysis and reporting capabilities

### For Rescuers
- Login/Logout functionality
- View and respond to emergency assignments
- Update status of rescue operations
- Access to critical information about affected areas

### For Citizens
- User registration and authentication
- Report emergencies or request assistance
- Access to safety guidelines and emergency protocols
- Receive real-time updates and alerts
